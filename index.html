KeeperHub

Organização

O KeeperHub é um hub para organizar a vida de manter uma casa, desenvolvido com uma estrutura modular para reunir diferentes funcionalidades em uma mesma aplicação. Entre seus módulos está o Controle de Medicamentos, desenvolvido para facilitar o gerenciamento e a visualização dessas informações.

  • Desenvolvimento de uma estrutura modular e organizada.
  • Criação e evolução do módulo de Controle de Medicamentos.
  • Uso de Git e branches para organização do desenvolvimento.
  • Interface responsiva e componentes reutilizáveis.
  • Atuação como gerente de banco de dados e organização do código do projeto.
