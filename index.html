Projeto destaque

KeeperHub

Uma aplicação construída para crescer.

O KeeperHub é um projeto desenvolvido com uma estrutura modular, pensado para organizar diferentes funcionalidades dentro de uma mesma aplicação. Entre seus módulos está o Controle de Medicamentos, desenvolvido para facilitar o gerenciamento e a visualização dessas informações.

  • Desenvolvimento de uma estrutura modular e organizada.
  • Criação e evolução do módulo de Controle de Medicamentos.
  • Uso de Git e branches para organização do desenvolvimento.
  • Interface responsiva e componentes reutilizáveis.
